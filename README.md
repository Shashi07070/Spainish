# Quince Días

A 15-day Spanish course for English speakers, from A1 to B2. One static page, no build step.

- Daily lesson: 10 words, 4 phrases, a grammar note, with pronunciation and audio
- An ancient memory technique each day (method of loci, Vedic chanting, imitatio, dictation and more)
- Daily 10-question quiz and a final exam on Day 15
- Spaced-repetition review deck (1, 2, 4, 8, 16 days)
- Progress saved in the browser (localStorage)

Open `index.html` in a browser, or host the folder on GitHub Pages. The `audio/` folder holds 210 mp3 clips generated with the Kokoro voice model (Apache-2.0). The page falls back to the browser voice if a clip is missing.
